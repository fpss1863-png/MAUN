# MAUN — مساعد القيادة الذكي

## النشر
ارفع كل ملفات هذا المجلد على نفس مستودع GitHub (استبدل القديم)، وVercel يحدّث الموقع تلقائياً.

## تفعيل الحسابات (Supabase) — اختياري
1. Supabase → SQL Editor → الصق `supabase.sql` وشغّله.
2. Authentication → Providers → Email (مفعّل).
3. Project Settings → API → انسخ Project URL و anon public key وضعهما في `config.js`.
   (مفتاح anon عام بطبيعته؛ الحماية من سياسات RLS في السكربت.)
بدون هذه الخطوة: الملفات والإعدادات تُحفظ على الجهاز فقط.

## الاستخدام
شاشة البداية ثم ابدأ. المعايرة تلقائية، وإن فشلت اطلب اليدوية من الإعدادات ثم الكاميرا.
للتجربة الآمنة استخدم «فحص فيديو». لا تتعامل مع الجوال أثناء القيادة.
